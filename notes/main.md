# Redis main 方法主要工作总结

1. **测试模式处理**
   - 检查是否以 test 参数启动，若是则运行内置单元测试并退出。

2. **基础环境初始化**
   - 初始化随机数种子、内存分配器、时区、哈希种子等。
   - 设置 umask，保证文件权限安全。
   - 解析可执行文件路径和参数。

3. **配置加载**
   - 解析命令行参数，支持从文件、stdin 或命令行加载配置。
   - 支持 --help、--version、--test-memory、--check-system 等特殊参数。
   - 支持 Sentinel 模式的特殊初始化。

4. **系统检查**
   - 检查 Linux 下的内存相关设置（如 overcommit、THP）。
   - 检查 Xen 虚拟化、ARM64 COW bug 等系统兼容性问题。

5. **守护进程/系统服务支持**
   - 根据配置决定是否以守护进程方式运行（daemonize）。
   - 支持 systemd/upstart 等系统服务管理。

6. **日志与启动信息**
   - 打印启动 logo 和版本信息。
   - 输出配置加载和初始化日志。

7. **核心服务初始化**
   - 调用 initServer() 初始化 Redis 服务器各项全局状态、数据结构、监听端口等。
   - 创建 PID 文件、设置进程标题、检查监听端口 backlog。
   - 初始化集群、模块、ACL、监听器等子系统。

8. **数据加载**
   - 加载 RDB/AOF 持久化数据到内存。
   - 加载 AOF manifest、处理 appendonly 配置。

9. **准备接受连接**
   - 日志输出“Ready to accept connections”。
   - 通知 systemd 服务已就绪。

10. **主事件循环**
    - 进入事件循环 aeMain(server.el)，开始处理客户端请求和定时任务。

11. **退出清理**
    - 事件循环退出后，清理事件循环资源并退出进程。

---
**简要总结**：main 方法负责 Redis 服务器的参数解析、配置加载、环境与子系统初始化、数据加载、监听端口、进入主事件循环，是 Redis 启动的总控流程
